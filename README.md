# 夜幕拾荒者 · Godot 正式版

这是正式 APK 版本的新工程，基于 Godot 4.x。现有 H5 与 Cocos 工程未被修改。

## 当前可运行内容

- 1280×720 横屏画面与移动端拉伸配置
- 左下虚拟轮盘，支持多点触控；编辑器中可用鼠标拖动测试
- Q版像素占位角色与自动瞄准射击
- 随时间加速刷新的敌人、碰撞伤害、经验拾取和升级
- 跟随玩家循环绘制的无边界背景
- 为移动端性能准备的实体数量上限

## 打开方式

1. 安装 Godot 4.3 或更高的 Godot 4 稳定版。
2. 在项目管理器中选择“导入”。
3. 选择本目录下的 `project.godot`。
4. 点击右上角运行按钮或按 F6/F5。

## Android 导出准备

在 Godot 编辑器中安装 Android Build Template，并配置 Android SDK/JDK。完成首轮玩法迁移后再设置正式包名、签名和商店图标，避免过早固化包体配置。
